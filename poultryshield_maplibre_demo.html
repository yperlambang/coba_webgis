Analisis Spasial (Turf.js)

Bukan sekadar styling — empat langkah geoprocessing berikut dihitung langsung di browser saat halaman dimuat, memakai Turf.js (library analisis spasial, satu keluarga dengan MapLibre/GeoLibre):
1. Buffer — radius 3 km dihitung di sekeliling tiap farm berstatus Bahaya Sedang/Tinggi.

2. Overlay (union) — seluruh buffer yang tumpang tindih digabung jadi satu poligon zona risiko.

3. Spatial join — farm berstatus Aman/Waspada yang jatuh di dalam zona itu ditandai "terpapar" meski skor individunya masih baik.

4. Nearest-distance — jarak tiap farm ke farm Bahaya Tinggi terdekat dihitung (lihat saat hover titik farm).
Contoh mandiri (self-contained) untuk pengujian di GitHub Pages · basemap: OpenFreeMap (OSM data) · dibuat sebagai bahan diskusi opsi integrasi MapLibre GL untuk PoultryShield, bukan produk akhir.
